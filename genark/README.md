# Lavira · 武汉城市具身仿真 (three.js)

双击 `index.html` 即可运行（离线可用，需保持本文件夹结构）。

渲染使用 WebGPU（three.js 0.187 的 WebGPURenderer + TSL）：请用新版桌面 Chrome / Edge 打开。合并 WebGPU 之前的 WebGL 版本备份在 `../wuhan-sim-webgl/`（需把本目录的 `packs/city` 和 `packs/robots` 拷过去才能运行）。

- `index.html` — 页面（约 15 KB）
- `engine.js` — three.js + cannon-es + 仿真器代码
- `packs/` — 按需加载的资源包
  - `tex.js` 材质，`ui.js` 字体与 logo，`g1_home.js` 家用 Unitree G1
  - `city/` 武汉中心区 12 × 13 km 的 OpenStreetMap 数据（156 个 1 km 分块 + 路网）
  - `city_water.js` 全城水域轮廓（大地图用）
  - `robots/` 102 个机器人 URDF 模型（每个一个文件，用到才加载）

## 设定：2049 年的武汉
机器人已经融入日常生活，所有工作都由机器人完成，物资按需领取；人类不用上班，每天做自己喜欢的事。玩家是一台机器人（默认 Unitree G1），
可以随时切换、召唤、接管其他机器人和车辆。

## 玩法
- **出生点**：武汉天地临江一栋住宅塔楼 22 楼（全楼 27 层）的江景大平层，约 290㎡：客厅、阳台和主卧朝长江，看得到长江二桥；大理石与人字拼木地板、藻井灯槽、酒柜、茶室、主卧套间（步入式衣帽间、石材浴室独立浴缸）、书房，以及家用机器人充电位、全息屏、调光玻璃。有 12 项家务可做。
  电梯前按 `F` 选楼层：22 楼家 / 1 层街道 / 1 层大堂 / B1 车库。在地图上点目的地会自动先去乘电梯。
- **地下车库**：5,700㎡，走近车辆按 `F` 接管，沿出口坡道可直接开上街道，也可以从街面开回车库。
- **车辆**：12 种原创新能源概念车（无人驾驶，车顶青蓝色灯条）和 8 种原创经典燃油豪车（长头 GT、礼宾轿车、楔形超跑、方盒越野、肌肉车、敞篷跑车、行政轿车、豪华 SUV，属于收藏车，路上约一成），35 种车漆。每种车有自己的声音（电机啸叫 / V8、V12、柴油发动机，换挡、收油回火），声音由程序合成，尚未经人耳试听。碰撞按分区累积损伤：凹陷、引擎盖弹起、玻璃碎、保险杠脱落，性能下降，冒烟起火直至爆炸（燃油车火球，电动车电池喷射），残骸由拖车机器人拖走；`sim.vehicle.setDamage(false)` 可关闭。
- **地铁**：10 条线、92 座车站；1 号线是高架轻轨。在出入口按 `F` 进站，站台等车，车门打开后走进车厢，到站走出去即下车（车内按 `T` 可选全网任意站，自动规划换乘）。换乘站是一座连通的多层车站，沿“换乘 X 号线”导向步行即可到另一条线的站台（有楼梯、扶梯和换乘电梯）。乘客固定在车厢里，只在开门时上下车，有座就坐、没座扶杆站立。行车时间约 6 倍压缩。
- **室内**：每一栋楼都能进：住宅楼进门厅坐电梯上楼，写字楼进前台和办公层，厂房类是垂直农场、物流中心、机器人工坊等，公共建筑是图书馆、体育馆、展厅等。临街店铺有 16 种 2050 业态（机器人维修充电、按需取货点、驿站、面馆、茶馆、麻将馆、创客工坊、全息游戏厅、诊所亭、无人机港、花圃、汉剧社、书咖、裁缝、画室、无人便利店），每家都有值守的服务机器人和可以做完的流程。医院可走完挂号 → 看诊 → 取药；商场、超市、学校等室内的门、抽屉、家电、开关、货架商品都能操作，右上角是该场景的任务。
- **居民与机器人**：人类居民只说武汉话（带普通话注释，优先播放真人录音）；服务机器人只说普通话的岗位播报。外卖和快递由四轮配送小车送到小区门口的驿站，再由四足和人形机器人送到楼门口，你也可以在驿站接单送件。居民会请你跑腿，送达得一个好评。行人和机器人只走人行道和斑马线。
- **地标**：黄鹤楼（可登顶层回廊）、武汉长江大桥、龟山电视塔、江汉关、长江二桥、武汉天地里弄等 12 处按公开资料重建，走近按 `F` 看介绍牌或互动。
- **夜晚灯光秀**：切到夜晚（`T`）后，两岸楼群、桥梁和地标按同一节目循环播放（约 3.5 分钟），带天空光束。
- **一键到达**：`J` 打开地点面板（22 个经典地点和“回家”）；大地图（`M`）单击可选导航或传送，右键直接传送，可搜索；指令栏输入“传送 <地名>”。
- **小地图**：左下角，默认车头朝上，按 `O` 或点小地图切换北朝上。
- **机器人库**（`B`）：93 个当前厂商公开的机器人模型（宇树、智元、众擎、银河通用、星海图、松灵等）和 20 种车辆。所有机器人都能用同一套按键：坐下（任意椅子、凳子、沙发、长椅）、翻越、抓放、开门等动作按各自身体结构适配，做不到的会给替代方式或提示（例如轮式底盘不能翻越）。带“非商用 / GPL”标记的型号商用前请确认许可，地址加 `?permissive` 可隐藏它们。
- **画质**：`[` / `]` 降 / 升一档（流畅 / 均衡 / 精细），`\` 回到自动。
- **电台**：`,` / `.` 换台，`/` 开关。
- **大模型对话（DeepSeek）**：配置在 `packs/llm_config.js`。**把这个文件夹发给别人之前，请删掉该文件里的 apiKey。**
- **武汉话录音**：`packs/voice_wh.js` 剪自第三方配音视频，**仅供本机自用；公开分发前需获得配音者许可，或直接删掉该文件**。
- 台词整理自公开资料并由程序编写，未经武汉本地人审校。

| `C` / `Z` | 下蹲 / 趴下爬行（四足：趴下；升降柱机器人：降下） |

| `F` | 互动：交谈、进门 / 进店 / 进站、开门、开关、拾取、坐下 / 起身（任何椅子、凳子、沙发、长椅、床沿）、接管车辆 / 下车 |
| 鼠标左键 / 右键 | 当前手的动作（抓取 / 放置 / 操作）/ 按住精细模式（放大、慢速、精确放置） |

脚本与测试：游戏逻辑内部仍使用原来的“逻辑键码”（如 `KeyE` = 互动），`g.keys.add(...)`、`sim.onKey(...)` 和 `tools/` 里用合成事件的测试脚本不用改；
只有真实键盘事件（或设置 `window.__physKeys = true`）才按上表的物理键位翻译。键位表在 `src/controls.js` 的 `BINDS` 一处修改。

## 脚本接口
浏览器控制台里的 `window.sim`：`sim.robots()`、`sim.spawn(id)`、`sim.control(uid)`、`sim.goto('黄鹤楼')`、
`await sim.observe({rgb:true, depth:true, seg:true})`（带图像时返回 Promise）、`sim.act({vx, vz, duration})`、`sim.weather('rain')`、`sim.say('召唤 go2')`、
`sim.env.reset(goal)` / `sim.env.step(action)`、`sim.scenes()` / `sim.loadScene(id, {seed})` / `sim.objects()` / `sim.tasks()` / `sim.taskStatus()`、`sim.travel(name)`、`sim.metro.enter/board/alight/leave/state`、`sim.setPlanner(fn)`；事件 `sim.on('talk'|'mission'|'enter'|'exit'|'shop', fn)`。

源码与构建脚本在 `../g1-home/`（`node build.mjs`）。
