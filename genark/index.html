    操作说明

    WASD
    行走 · 按住 Shift 奔跑 · 按住 Q 侧身横移
    空格
    跳跃（可跳上跳箱、跨过栏杆）· 面对矮墙时撑手翻越
    X
    趴下爬行 / 起身（可从餐桌、钻架下面爬过）
    鼠标
    转动视角 · 滚轮调节距离
    左键 / 右键
    左手 / 右手：抓取准星对准的物体，再次点击放到准星位置
    E
    操作门、冰箱、抽屉、开关、家电 · 对准沙发 / 床 / 长椅坐下，再按起身
    G
    松开双手里的物体
    C
    下蹲 / 起身
    V
    第一人称 / 跟随视角
    T
    切换时间：上午 / 黄昏 / 夜晚
    F R
    挥手 · 重置场景
    M N
    全城地图（点击任意位置自动前往）· 导航到当前城市任务
    F 上下车
    靠近任意车辆（行驶中、路边停放、电动车、公交）按 F 上车；W/S 油门·刹车/倒车，A/D 转向，空格手刹，G 喇叭，L 车灯
    E 交谈
    和居民、早点摊主用武汉话聊天（带普通话注释）：数字键选择，问路、跑腿赚钱、买过早
    , . /
    电台：上一个 / 下一个 / 开关（7 个原创程序化电台）
    B Tab
    机器人库（生成并接管）· 在已生成的机器人之间切换
    P
    机载传感器：RGB / 深度 / 语义分割 / 激光雷达
    Enter
    文字指令：去黄鹤楼、召唤 go2、跟随、天气 雨、放一棵树…
    123
    画质：流畅 / 均衡 / 精细
